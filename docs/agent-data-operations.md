# AgentData 任务、审计与诊断

第四阶段已接入 Agent 数据工作台。重启 Electron 后加载更新；应用不会为此自动重启、安装 CodeGraph 或创建索引。

## 任务

用户任务默认显示，后台系统任务放在折叠区。列表按“来源 + ID”区分任务；系统任务只读，不提供取消、重试或删除入口。未知进度显示“未提供百分比”。

筛选与“清理已结束”仅作用于已加载的用户任务，继续加载可扩大查看范围。清理前显示数量并要求确认，只删除终态任务记录，保留 Wiki、索引和审计。

- 点击任务行查看原始类型、ID、目标资源、阶段、错误和经过字段筛选的输入/结果摘要。
- 后端根据资源是否存在、是否已有活动任务及任务类型决定可用操作，执行前再次检查。
- “重试”创建新 ID，并记录旧任务 ID；旧记录及失败状态保留。Wiki 重试需确认当前模型和原资料范围，可能调用模型；CodeGraph 重试不走模型确认。
- 取消后先显示“正在取消，等待确认”，执行器确认后才显示已取消。

工作台共用一个任务监视器。已观察到的后台活动任务结束后，即使没有手动打开详情，概览也会刷新；未加载页面的活动计数下降会触发汇总刷新。首次加载历史记录不会伪造完成通知，隐藏或失焦时暂停轮询。

## 操作记录

在“审计诊断 → 操作记录”按动作、资源和本地日期筛选，服务端分页，每页 50 条。资源筛选必须同时填写类型与 ID；未填完整时停止分页和导出。

“导出当前筛选”从筛选结果开头读取，最多 500 条，界面标明是否截断，可复制或下载 JSON。列表、详情和导出共用后端字段投影与脱敏规则；系统任务原始输入输出、捕获正文和模型正文不进入导出。资源删除后仍能读取已保存的名称快照。

脱敏覆盖敏感键名及可识别的认证文本，不保证识别任意自由文本中的秘密。管理错误保留截断信息，可能含本地路径；对外分享前请检查导出内容。

## 运行诊断

检查区分“正常 / 需要处理 / 未检查”，读取已有 Wiki 文件、哈希和索引信息。检查本身不重建索引、不启动 MCP 或模型。

进入面板默认打开运行诊断，并按“需要处理 / 未检查 / 正常”分别计数。

- Wiki 文件与清单不一致时，可确认“重建页面清单”；该操作不调用模型、不改正文，完成后显示问题文件。
- “打开问题文件”只提交诊断 ID，由主进程重新验证知识库和路径。
- CodeGraph 使用内置 SDK；诊断等待真实 SDK 状态，区分平台依赖缺失、索引过期、部分/失败索引和正常统计，不再把索引目录存在当作连接正常。安装包缺少 SDK 时提示检查安装包，不自动安装 CLI；旧 CLI 状态仍可用于识别历史诊断数据。

## 概览与验证边界

概览的最近页面携带知识库 ID 与页面 ID，任务入口携带来源与 ID。切面板保留筛选和草稿，替换编辑目标前保留现有的未保存确认。

本阶段自动回归使用临时 SQLite、文件和执行器替身；浏览器使用真实组件与标注的内存数据。未运行真实模型抽取或 CodeGraph 索引写入，也未修改用户数据库。完整结果见[第四阶段交付记录](./superpowers/plans/2026-09-05-agent-data-workbench-operations.md#第四阶段交付记录2026-09-05)。

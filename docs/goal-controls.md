# 会话目标：编辑、暂停与恢复

目标条与详情只针对其所属会话操作。运行中的目标可以暂停；未耗尽本批次预算时，点击“恢复目标”继续使用同一批次已用轮数，不增加可用轮数。达到上限后会显示“已达本批次轮次上限”，入口改成“开启新批次”：同一目标的批次内轮数从零开始，累计轮数、历史和完成条件不清除。请求或运行异常导致的暂停会显示原因，用户可在确认原因后人工恢复；模型不能替用户重新开启批次。

编辑条件时，下一轮进度或计时更新不会覆盖未保存输入。点击保存或按 Enter 后，只有本次操作的提交回执确认已写入原会话，编辑器才退出；投递成功、补拉到相同条件或其他操作的更新都不是保存成功。回执丢失时，草稿仍在；直接重试使用同一个操作标识，不重复追加。写盘失败会提示未保存并保留草稿；远端条件发生冲突时，需明确选择“载入最新版”（放弃草稿）或“基于最新版提交”（保留草稿、按当前版本重新提交），不会静默覆盖。Esc 可取消条上的编辑。

如果暂停记录未能保存，界面会明确写“已停止，暂停未保存”，而不是伪装成已持久暂停；“重新读取目标状态”只按原会话读取，不启动新的运行。排除写入故障后，可人工执行 `/goal resume`：当前 owner 先补写并核验原暂停，再提交恢复；等待修复的时间不计入运行时长，任何一步失败都保持停止，不靠刷新偷偷恢复。详情同时列出当前批次已用轮数和累计轮数；旧续跑卡片仍按原轮次显示，新卡片可展示批次内轮次。

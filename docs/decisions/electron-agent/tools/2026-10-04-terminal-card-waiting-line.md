## 背景
运行中的 bash 卡片在收到第一块输出前只有命令头，输出区不渲染，输出来了才冒出一块区域；多行命令还会把头部撑到 150px。看起来像「等跑完才显示结果」。复制按钮只复制输出，且运行中隐藏。

## 决定
输出区从一开始就渲染。没有输出时放一行「等待响应中」，pi 先发的空 `content: []` 也算没有输出；这一行和一行输出等高，第一行输出到来时卡片不跳。之后随输出长高，到 224px 上限后在区内滚动。结束时不收缩，无输出显示「无输出」。命令头只显示首行，多行时追加 ` …`，完整命令放在 `title` 和复制里。复制按钮常驻，点开是「复制命令 / 复制结果 / 复制全部」；还没有输出时「复制结果」禁用；「复制全部」按 `$ 命令` 加输出拼接。

## 放弃的方案
- 运行中直接按 224px 上限铺开：只有一行结果的命令结束时要从 224px 收回去，卡片闪缩。试过，用户否掉了。
- 运行中满高、结束后也保持满高：短输出（日期、版本号）会留一大块空白，历史里堆满这样的卡片。
- 复制按钮单击直接复制全部、菜单放右键：右键在卡片上不可发现，三个选项也是用户明确要的。

## 后果
多行输出仍会让卡片在运行中逐步长高到 224px，这是有意的。占位行和输出行必须保持相同的 padding 与 line-height，改其中一个样式时要一起改。

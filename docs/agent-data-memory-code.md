# 代码索引使用说明

打开侧栏「代码索引」，选择一个已登记的项目。没有索引时点「建立索引」；已有索引时可点「同步索引」。Agent 的 `code_explore` 与桌面面板使用同一套本地 CodeGraph 索引。

- 不输入关键词时浏览文件；输入关键词时检索符号。点结果查看源码，使用路径区分同名符号。
- 关系面板可以查看调用者、被调用者和影响范围。缺失或越界行号会显示错误；「使用系统打开文件」打开已验证的文件，精确行号定位在面板中完成。
- 自动同步只维护已有索引。查询会激活文件监听，读取状态不会。增量同步期间仍可查询上次提交的索引；全量重建期间显示忙碌。面板在同步期间刷新状态，不需要打开任务中心。

代码索引和索引任务各自的存储位置、进程边界及开关见[架构文档](./architecture.md#代码索引)。

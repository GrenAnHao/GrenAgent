# AgentData Memory 与代码详情

## Memory

打开 Agent 数据工作台的 Memory 面板即可浏览最近记录，无需先输入关键词。每页 50 条，支持继续加载；切面板和后台刷新保留已加载窗口、筛选与选择。

- **记忆**：事实与偏好（L1）、场景摘要（L2）、长期画像（L3）。旧 L0 可读、可保持原层级编辑，但不能人工新建 L0。
- **对话记录**：独立保存的捕获原文，只读，不计入 Memory L0；详情保留命中片段和完整原文。
- **归属筛选**：全部项目、全局或某个真实项目。管理页的项目筛选仅列该项目记忆；Agent 召回仍兼容项目与全局记忆。

“本用户记忆总数”是全局摘要，不是当前关键词或筛选的匹配数量。结构化 JSON 以字段、数组展示，折叠的“原始 JSON”保留真实原文，不重新序列化。

### 人工维护

新增必须明确选择全局或真实项目，不默认使用当前聊天或临时会话目录。编辑保持记录 ID，并检查原 revision；归属改变不抹掉原来源工作区。修改来源为自由文本后不再声称关联原会话。

人工保存后记录标为 manual，后续自动提炼不会覆盖它。同文自动记录使用独立去重位置；连续人工改写后仍能保留各份人工内容。

`Ctrl+S` / `Meta+S` 保存，版本冲突保留正文、归属和来源草稿；重新载入前需确认放弃修改。提交和重载期间禁止重复操作，迟到响应不会写入另一记录。删除记忆仅删除指定用户的稳定 ID，不删除来源对话。

### 来源会话

详情只匹配现有会话，点击打开前再次查询。成功时使用真实 `cwd/path` 打开并切回聊天，不新建会话或拼造 JSONL 路径。

“未记录来源”“会话已移除”和“来源状态未获取”分别表示缺少标识、已确认无匹配和查询失败。记忆移到全局后仍按原来源工作区匹配。

## Code

代码项目只从真实项目选项中选择。项目被移除或识别为临时目录后，面板立即撤销旧目标的查询、详情和同步入口。

- 空搜索浏览文件；输入关键词检索符号；“相关上下文”显示只读上下文结果。
- 点击结果可读取项目内源码并定位真实行号，同名符号用文件路径消歧。
- 调用者、被调用者和影响分别使用既有只读工具。未知 provider 结构展示原文，不虚构关系图、空结果或统计数字。
- 缺失或越界行号明确提示，不擅自跳到第一行。“使用系统打开文件”只保证打开已验证的项目内文件；行号跳转在面板预览中完成。

未检查、未索引和查询失败是不同状态。文件、节点、边的数量来自内置 SDK；未能读取时显示“未提供”。仅有 `.codegraph` 目录不算已初始化，SDK 打开数据库失败会显示真实错误。只有明确点击“建立索引”或“同步索引”才创建任务，不依赖或自动安装全局 CLI。

Electron 固定使用内置 CodeGraph 1.6.0。搜索、源码和关系共享结构化节点 ID，支持同名符号消歧；未知旧文本保留原文，不从 Markdown 猜测文件与符号。索引过期或上次构建中断时，下一次显式同步会执行全量索引，但不会删除工作区或自动重克隆。

SDK 不启用自动 watcher。取消请求需等待当前 SDK 操作安全结束，已经写入的索引增量会保留；尤其 1.6.0 的增量同步内部没有传递 AbortSignal，不能承诺立即中止。应用退出会等索引写入和任务记录结束再释放连接。

创建任务后留在原页，点击“查看任务”才定位该任务。索引完成后刷新当前查询和关系，保留源码与滚动。各项目搜索词独立保存；隐藏面板暂停新查询，但不声称取消已经发出的底层只读调用。

## 兼容与验证边界

本阶段沿用前两阶段的任务监视器、主进程管理入口和项目校验，没有引入新调度器、实例池或多用户系统。Memory 管理查询全部约束 user_id；新管理方法不接受 socket payload 自选管理权限。

工作台最初验收使用临时 SQLite、文件和可控执行器；浏览器验收使用真实组件与明确标注的内存替身。2026-09-06 的内置 SDK 迁移另外运行真实临时项目的建图、增量同步、RPC 查询与打包资源探针，未操作用户数据库或已有索引。全量类型检查仍有项目内其他错误，不能将构建成功等同于类型全绿。

在 `electron-agent/` 运行 `pnpm test:codegraph`，使用应用自己的 Electron/Node 运行 SDK 测试，避免全局 Node 版本影响结果。测试进程设置上游建议的 `--liftoff-only`；大型仓库及常规 GUI 启动下的 WASM 压力仍需专门验证，不能由小型索引样例推断。

重启 Electron 后加载新增后端和界面。统一任务、审计与诊断现已完成，参见[使用说明](./agent-data-operations.md)；应用不会自动重启或提交代码。

# Pi 0.84.2 Upgrade Implementation Plan

> **For AI agents:** Required sub-skill: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task by task. Use the checkbox syntax (`- [ ]`) to track progress.

**Goal:** Upgrade the Pi sidecar core package to `@earendil-works/pi-coding-agent@0.84.2` and declare Pi's required Node.js baseline.

**Architecture:** The sidecar keeps its existing external Pi dependency. Its manifest declares the new compatible range and Node.js requirement; npm regenerates the lockfile from that manifest. The development prerequisite documents the same runtime baseline so local and CI setup remains consistent.

**Tech Stack:** Node.js, npm lockfile v3, TypeScript, esbuild, Node test runner.

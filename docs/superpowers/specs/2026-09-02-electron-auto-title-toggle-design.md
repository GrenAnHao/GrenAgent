# Electron 自动对话标题开关设计

## 目标

恢复 Electron 首轮对话结束后的自动标题生成，并在“通用与模型”设置页增加开关。用户关闭开关后，后续未命名会话不再调用标题模型；已有标题保持不变。

## 范围

- 修改 Electron 设置 schema 和相关测试。
- 修改共享 `auto-title` 扩展的运行时开关读取与标题模型失败回退。
- 保持 Tauri 设置页不变。Tauri 没有新增开关，缺少配置时仍沿用默认开启行为。
- 不修改会话列表布局、手动重命名和已有标题。

## 现状与问题

Electron 已把 `titleModel` 写入 `runtime-settings.json`，sidecar 也加载了 `auto-title` 扩展。侧栏监听 `session_info_changed`，因此标题写入后可以刷新。

当前链路有两个缺口：

1. 扩展在模块加载时只读取 `process.env.AUTO_TITLE`。设置页新增开关后，这种读取方式无法响应 `runtime-settings.json` 的热更新。
2. 指定标题模型缺少鉴权、请求失败或返回空内容时，当前代码不使用对话模型补救。会话继续保留默认标题，界面也没有可恢复路径。

## 设置与界面

在 Electron `SETTINGS_SCHEMA` 的“通用与模型”分类中，把新字段放在“对话标题模型”之后、“压缩上下文前确认”之前：

```ts
{
  key: 'AUTO_TITLE',
  label: '自动生成对话标题',
  type: 'boolean',
  default: '1',
  description: '首轮对话结束后生成简短标题（默认开）',
}
```

现有 `SettingFieldInput` 负责渲染。字段左侧显示名称和说明，开关位于设置行最右端，与“压缩上下文前确认”开关共用右侧对齐线。

关闭开关不会隐藏或禁用“对话标题模型”选择器。用户仍可先选好模型，再决定何时开启生成。

设置沿用手动保存流程。`SettingsService` 把 `AUTO_TITLE` 写入 `settings.json` 和 `runtime-settings.json`；扩展通过文件监听获取新值，无需重启 sidecar。

## 标题生成行为

`auto-title` 在每次 `agent_end` 处理时读取：

```ts
(getConfig('AUTO_TITLE') ?? '1') !== '0'
```

该判断保留环境变量回退，同时允许 Electron 保存后的配置热生效。

处理顺序如下：

1. 开关关闭时返回。
2. 子代理会话返回。
3. 已有 `session_info.name` 时返回，避免覆盖自动标题或手动标题。
4. 提取首条用户消息。
5. 使用 `titleModel` 生成标题。
6. 指定模型抛错或返回空内容时，如果当前对话模型与指定模型不同，使用当前对话模型重试一次。
7. 得到非空标题后调用 `pi.setSessionName`。

标题任务继续在后台执行，不延长首轮 `agent_end`。回退最多发生一次，避免循环调用或重复计费。两次尝试都失败时记录现有 `[auto-title] error` 日志，不影响对话。

## 错误与竞态

- 用户在标题生成期间手动命名时，写入前再次检查会话是否已有名字；若已有名字则放弃自动标题。
- 用户关闭开关只影响关闭后触发的 `agent_end`。已经开始的后台任务可以完成，但写入前仍遵守“已有名字不覆盖”。
- 没有首条用户消息、没有可用模型或模型没有鉴权时保持默认标题。
- 生成失败不向聊天区或设置页抛出错误。

## 测试

### 扩展测试

- 缺少 `AUTO_TITLE` 时默认启用。
- `AUTO_TITLE=0` 时不调用摘要和 `setSessionName`。
- 已命名会话和子代理不生成标题。
- 指定标题模型成功时写入一次标题。
- 指定模型失败或返回空内容时使用当前对话模型重试。
- 回退也失败时不写标题。
- 后台请求完成前用户手动命名时不覆盖手动标题。

### Electron 测试

- schema 包含 `AUTO_TITLE`，类型为 boolean，默认值为 `1`。
- 设置字段未落盘时开关显示开启。
- 切换后表单保存 `AUTO_TITLE=0/1`。
- 新设置行使用现有 inline boolean 布局，开关位于右侧控制列。

## 验收标准

- 新建 Electron 对话完成首轮后，侧栏显示生成标题。
- 关闭开关并保存后，新对话完成首轮不会调用标题生成。
- 再次开启并保存后，无需重启 Electron 或 sidecar即可恢复生成。
- 开关位于独立设置行最右端，与其他 boolean 设置对齐。
- Electron 定向测试、扩展定向测试和 Electron 构建通过。

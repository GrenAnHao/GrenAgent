# 会话消息编辑与回退

- 日期：2026-09-22
- 状态：待审查
- 主题：桌面端编辑最后一条用户消息，以及把当前上下文中的用户消息回退到输入框。旧内容从画面、界面历史和本地会话里删除，不留旧分支。

## 1. 背景

用户消息菜单里已经有「回退到此」。它按消息时间戳找到会话条目后 `fork`，旧路径留在会话文件里。`编辑` 仍是禁用占位。

界面另外保存一份更长的显示历史。上下文压缩后，后端当前上下文变短，重载时如果显示历史更长，会用显示历史盖住后端结果。因此只改画面、不截显示历史，重新打开会话会把已删消息显示回来。

这次不使用 `fork`。`fork` 的结果是留下旧分支，和「本地也不保留旧内容」相反。

## 2. 目标 / 非目标

**目标**

1. 对话停下时，可以编辑最后一条用户消息。
2. 当前模型上下文里的用户消息可以回退，运行中也可以。回退先确认。
3. 两个动作都把该条消息的文字放进底部输入框。
4. 被去掉的内容从当前画面、界面历史和本地会话文件中删除。重新打开会话不再出现。
5. 回退确认之后的发送，以及编辑完成删除之后的发送，都是普通发送。

**非目标**

- 不退回工作区文件，不做文件快照。
- 不编辑助手回复或工具结果。
- 不回退压缩摘要之前、只存在于显示历史里的用户消息。
- 不在对话进行中编辑。
- 不自动发送。
- 不把原消息上的图片带回输入框。放进输入框的只有文字。
- 不删除尚未进入会话的引导或跟进队列。放入输入框只替换当前输入草稿。

## 3. 已确认的设计决定

| 维度 | 决定 |
| --- | --- |
| 编辑入口 | 只在对话停下、且是最后一条用户消息时出现。无确认 |
| 回退入口 | 当前模型上下文中的用户消息。运行中也能点。必须确认 |
| 输入 | 都使用底部输入框 |
| 编辑删除时机 | 按下发送时先取走文字，再删除，再发送这份文字 |
| 回退删除时机 | 确认后先记住文字，再停止正在跑的回合并删除，再放入输入框 |
| 确认后的发送 | 普通发送。输入框里的文字可以先改 |
| 取消回退确认 | 画面、会话和正在跑的回合都不变 |
| 失败 | 已删除的内容不恢复。已停止的回合不自动继续 |
| 存储 | 同一次截断会话文件和界面历史，两边剩下的对话相同 |
| 编辑未发送又回退 | 以回退为准，按回退规则立即删除 |

对话进行中，指当前回合还在跑，包括正在生成和工具仍在执行。对话停下，指没有这样的回合。

## 4. 行为

### 4.1 编辑

1. 点编辑：把最后一条用户消息的文字放入底部输入框。画面和会话先不动。
2. 按下发送：先取走输入框里的文字，再删除这条用户消息和它后面的内容，再发送这份文字。
3. 发送失败：旧内容不恢复。输入框文字留着，可以再按发送。

### 4.2 回退

1. 点回退到此：打开确认。
2. 取消：什么都不做。
3. 确认时这条已经不能回退：确认无效，并提示。不停止，不删除。
4. 确认成功的顺序：先记住这条用户消息的文字，再停止正在跑的回合，再删除这条和它后面的内容，再把记住的文字放入输入框。
5. 中途失败：停在失败的那一步并提示。已经停掉的回合不自动继续。已经删掉的内容不写回。
6. 之后按下发送：只发送输入框里的当前文字，不再删除。

### 4.3 重新打开

界面历史不得长过截断后的会话，也不得用截断前的显示历史覆盖回来。

## 5. 架构

三个单元：

1. **消息动作**：决定编辑和回退是否出现，以及回退确认。回退的可选消息来自后端当前上下文，不来自更长的显示历史。
2. **底部输入框**：承接文字。回退确认成功后，发送路径就是现有的普通发送。编辑的发送路径在普通发送之前先完成删除。
3. **会话截断**：把该用户消息及其后的条目从本地会话文件去掉，并把界面历史写成同一份剩余对话。不调用 `fork`。

编辑已经把文字放入输入框但还没发送时，用户又确认回退：丢弃这次编辑的待发送状态，执行回退。

## 6. 验收

工作区文件在全部路径上保持不动。

回退：

- 只出现在当前模型上下文里的用户消息上，运行中也能点。
- 助手、工具结果，以及压缩摘要之前只留在界面历史里的消息，没有回退。
- 取消确认后，画面、会话和正在跑的回合都不变。
- 确认后，回合已停；这条和它后面的内容从画面、界面历史、本地会话里消失；输入框是原文。
- 之后按发送，发出的是输入框里的文字，不再做第二次删除。
- 重新打开会话，已删内容不会再出现。

编辑：

- 只出现在已经停下的最后一条用户消息上。进行中不出现。
- 点下去只把原文放进输入框，旧内容还在。
- 按下发送时，先取走输入框文字，再删掉这条和它后面的内容，再发送这份文字。
- 发送失败时，旧内容不恢复，输入框文字还在，可以再发送。
- 还没发送时又确认了回退，按回退立刻删除。

# Pi 0.84.2 Upgrade Design

## Goal

Upgrade the sidecar's Pi core package from `@earendil-works/pi-coding-agent` `0.80.2` to `0.84.2` and align the project's declared Node.js baseline with Pi's requirement.

## Scope

- Update `cli/package.json` to use `^0.84.2`.
- Update `cli/package.json` `engines.node` from `>=22.5.0` to `>=22.19.0`.
- Regenerate `cli/package-lock.json` with npm so the resolved package and all transitive dependencies match the updated manifest.
- Update the Node.js prerequisite in `docs/development.md`.

## Compatibility

- Pi `0.84.2` requires Node.js `>=22.19.0`.
- Pi `0.83.0` removes deprecated TypeBox APIs. A repository-wide source check found no usages of the removed APIs.
- The local Node.js runtime is `v25.5.0`, which meets the new minimum requirement.

## Non-Goals

- Do not upgrade unrelated dependencies.
- Do not change existing sidecar behavior, extension APIs, or application release versions.
- Do not alter unrelated uncommitted workspace changes.

## Verification

Run from `cli` after the lockfile update:

1. `npm ls @earendil-works/pi-coding-agent --depth=0` resolves `0.84.2`.
2. `npm run typecheck` completes successfully.
3. `npm test` completes successfully.
4. `npm run build` completes successfully.

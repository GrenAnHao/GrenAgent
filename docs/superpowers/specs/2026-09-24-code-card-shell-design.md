# 代码卡片外壳

- 日期：2026-09-24
- 状态：待审查
- 范围：GrenAgent 桌面端工具卡片（`electron-agent`）
- 主题：写入、编辑、读取、检索共用一张圆角代码卡片。顶栏保留文件或语言图标，正文用直角的 diff 或高亮，不再折叠。横向滚动条只在鼠标放进代码区域时出现。

## 1. 背景

写入和编辑使用 `@lobehub/ui` 的 `CodeDiff`，读取、检索和 grep 使用 `Highlighter`。这两套组件的「完整模式」把顶栏和折叠做在一起：外层工具行已经能折叠，卡片里再折叠就是两层。关掉完整模式后，顶栏一起消失，正文自己变成圆角，并且短内容也会一直占着一条横向滚动条。

## 2. 目标 / 非目标

**目标**

1. 用我们自己的 `CodeCard` 做外壳。写入、编辑、读取、检索、grep 都套它。
2. 顶栏一直显示，不能点，没有折叠箭头。有文件名时，图标和文字都用文件名。没有文件名、只有语言时，文字用语言显示名，图标按该语言对应的文件类型来选。
3. diff 在顶栏右侧显示 `+N` `-N`。两者都是 0 时不显示。读取和检索没有这组数字。文件名过长时省略，右侧数字保持可见。
4. 外壳是圆角卡片。里面的 diff 和高亮是直角，贴着顶栏，不自带顶栏、圆角和滚动条。
5. 正文只有一条横向滚动。短行不出现滚动条，滚动条不占高度。鼠标放进代码区域时，滚动条浮在内容上；离开就消失。代码上下跟着对话一起长，卡片里不再纵向滚动。
6. 正文模块还没加载好时，顶栏先在，代码区域空着。不再用没有样式的纯文本先顶上。

**非目标**

- 不给卡片加复制按钮。
- 不给 glob、命令输出、通用 JSON 结果套这张卡片。
- 不改外层工具行的折叠。
- 不用截图测试滚动条。

## 3. 组件

`CodeCard` 放在 `electron-agent/src/features/tools/CodeCard.tsx`。

输入：

- `fileName`：有则顶栏用它，图标走现有 `FileIcon`。
- `language`：没有 `fileName` 时使用。显示名是给人读的名字（例如 `typescript` 显示为 TypeScript），图标用该语言的代表文件名（例如 `file.ts`）交给 `FileIcon`。未知语言显示原始字符串，图标用通用文件图标。
- `added` / `deleted`：可选。任一大于 0 时在顶栏右侧显示对应数字，颜色与现在工具行上的增删计数一致。都缺省或都为 0 时不渲染右侧。
- `children`：直角正文。

顶栏不接收点击，里面没有按钮。

语言显示名和代表文件名放在 `codeLanguage.ts`，和现有 `languageFromPath` 放在一起。已识别的语言都要有显示名和代表文件名：`BY_EXT` 里的每一种语言 id 各一条。

## 4. 谁使用它

- `FileDiffBlock`：顶栏用路径里的文件名、`languageFromPath` 只用于 diff 高亮语言、`added` / `deleted` 来自现有计数。正文是 `CodeDiff`，`fullFeatured` 为假，`showHeader` 为假，`variant` 为 `borderless`。
- `FileReadBlock`：顶栏用路径里的文件名。正文是不高亮顶栏的 `Highlighter`（不传 `fullFeatured`）。空文本仍不渲染，和现在一样。
- `GrepCard` 和 `CodeSearchCard`：每个文件一组一张 `CodeCard`，顶栏用该文件名。没有命中时仍只显示「未找到匹配」，不套空卡片。

`CodeDiff` 和 `Highlighter` 的根节点用样式压成直角、`overflow: visible`，使它们不再自己滚动。唯一的横向滚动口是 `CodeCard` 的正文区：`overflow-x: auto`，`min-width: 0`。滚动条默认不占高度；指针在正文区上时才显示细滚动条，离开后隐藏。

`LazyHighlighter` 和 `LazyCodeDiff` 在模块未就绪时渲染空，不再渲染纯文本 `<pre>`。这同时作用于卡片正文和其余调用处（例如通用 JSON）。顶栏不依赖这个模块，所以会先出现。

渲染失败继续由 `ToolExecution` 里现有的 `ErrorBoundary` 接住。`CodeCard` 不另做错误提示。

## 5. 测试

- `CodeCard`：有文件名时顶栏是该文件名，且顶栏内没有按钮。只有语言时顶栏是显示名（TypeScript），不是 `file.ts`。`added` 和 `deleted` 都为 0 时没有 `+` / `-`；有数字时出现在顶栏右侧。
- `FileDiffBlock`、`FileReadBlock`、`GrepCard`、`CodeSearchCard`：顶栏在，卡片内没有第二层折叠按钮。
- 滚动条行为由正文区的样式约定覆盖：默认不占高度，悬停才显示。不另开浏览器截图。

## 6. 成功标准

展开写入、编辑、读取或检索后，看到一张圆角卡片：顶栏是文件图标和文件名（或语言名），没有折叠箭头。diff 右侧有增删计数。正文直角贴着顶栏。短代码没有横向滚动条；只有行比卡片宽、并且鼠标放在代码上时，才出现一条不把内容顶下去的横向滚动条。

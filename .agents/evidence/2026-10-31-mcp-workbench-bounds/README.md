# MCP 工作台外框边界修复

根因：外层剩余高度有界，但中间 inner 禁止收缩，MCP grid 又有 480px 最小高度，长目录和工具列表把外框撑高。修复只限定 MCP：body 不滚动、inner 可收缩、grid 行最小高度归零，目录与详情分别内部滚动。

`npm run ui:check -- extensions-workbench` 最终为 153 passed / 0 failed，只运行 1/43 个场景。夹具含 24 台服务器和 40 个工具。

| 视口 | 修复后外框高度 | 外框底边 / 外层边界 |
| --- | --- | --- |
| 1420×880 | 695.81px | 852 / 852px |
| 1420×430 | 245.81px | 402 / 402px |
| 520×430 | 228.35px | 410 / 410px |

红灯的正常视口外框高 2458.22px、底边 2614.41px，外层可用底边仅 852px。红灯依据为滚轮操作之前就已失败的几何与外层 scrollHeight；首轮新探针的 wheel 参数顺序另行校正，最终使用真实纵向滚轮验证目录/详情互不带动及末项可达。

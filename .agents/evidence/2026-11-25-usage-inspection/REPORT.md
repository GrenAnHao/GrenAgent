# 用量统计：图表悬停与最近会话验收

在真实 Electron 窗口中用鼠标反复划过图表、排序和翻页，再从报表打开历史正文。使用合成用量和会话，未访问用户账本。

| 操作 | 实测结果 |
| --- | --- |
| 在明、暗主题来回划过首柱、中柱和末柱，再把鼠标移到浮层所在位置 | 首、中柱右侧提示，末柱翻到左侧；与柱边至少相隔 16px，浮层内的精确数值不换行。浮层不截获指针，下方日期仍能接管高亮。[浅色](trend-light.png) · [暗色](trend-dark.png) |
| 把窗口缩到 390px，在中间日期停留 | 左右均放不下时，提示移到横轴下方；当前柱和坐标仍可见。[窄窗](trend-narrow.png) |
| 在两个扇区的内缘、外缘、圆心和圆外反复移动 | 圆心与图例始终指向同一模型。移到空白恢复总量；总量与模型明细不同时出现。图例精确值浮层的计算背景在明暗主题分别为 `#FFFFFF`、`#1F2220`。[暗色](ring-dark.png) · [浅色](ring-light.png) |
| 在项目榜和最近会话中查费用 | 项目与模型卡等高，超过六七项在项目卡内滚动。Token 榜不列零用量项目；费用榜保留有实际预热费的项目。会话支持取消隐藏、搜索、清空、两向排序和每页 15 条；按费用降序后原在第二页的 $9.25 会话排第一。[最近会话](sessions.png) |
| 从用量表点击同项目和跨项目历史会话的数字单元格 | 工作台进入聊天页，读取目标路径并显示对应正文；已删除的记录没有失效跳转。[打开历史正文](opened-history.png) |

账本仍按 UTC 日汇总，界面显示该桶的本地起止时间。时区测试覆盖上海跨午夜和洛杉矶夏令时切换。SQLite 测试用 56 个符合条件的会话验证：最贵的一条不在最新 50 条内，但可从桌面完整摘要排到第一；未请求完整摘要的调用方仍只取最新 50 条。

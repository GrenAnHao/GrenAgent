## 实际检查的差异

- **布局与换肤。** 真实 Electron 在同一窗口比较可见元素的坐标、尺寸、字体、圆角、边框、内距和滚动位置，不舍入到整像素。MCP 的两张图均在 1420 × 880 CSS 像素的窗口选中 `antd`，显示同样的 8 个工具。换肤首帧检查服务名和 SVG 的实际前景；过渡只改变背景与边线。
- **品牌与危险操作。** 默认操作按钮在两种主题下都是填充变体，新增是主按钮。浅色品牌色为 `#4A6B4E`，目录选中与导航共用半透明鼠尾草绿和细边框。移除手写的白卡选中投影，删除留在危险色体系。
- **滚动与窄窗。** MCP 目录与工具区用 6px 透明轨道。实际像素采样验证浅色滑块从黑色 14% 到悬停 25%，暗色从白色 12% 到 25%。目录长名自动省略并保留完整标题。360px 宽窗下四个扩展子页的操作和标题对齐；550px 高窗内，滚轮只滚有溢出的技能目录。
- **字体。** 一级标题为 18px / 600 / 1.3 / −0.02em，详情标题 16px。导航、常规按钮和搜索输入为 13px，辅助文字与密集操作为 12px，标签为 11px，工具名为 12.5px / 500 的 JetBrains Mono。会话阅读字号偏好独立保留。

## 验收结果

[真实 Electron：6 个定向场景，832 项断言全部通过](electron.log)。其中 MCP 管理 229 项、扩展资源库 204 项、主工作台布局 268 项、代码索引 52 项、字号 45 项、外观设置 34 项。使用真实组件与渲染器，后端 I/O 用测试数据。

同窗切换时，MCP 管理页的 413 个可见元素没有位移。另在四个扩展子页、主对话与代码索引对照了可见元素的位置、尺寸与字体。命令页的普通「删除」按钮和 MCP 详情的文本「删除」按钮在两种主题下都显示危险色。

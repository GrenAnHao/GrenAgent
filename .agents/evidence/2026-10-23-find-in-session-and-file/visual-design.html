③ 高亮颜色（二选一）

所有命中项一个底色，当前项换成更实的颜色并且文字改成高对比色。实现用 CSS Custom Highlight API，不改 DOM，所以链接、代码、加粗里的命中都能高亮，原有格式不受影响。限制：它只能改背景色和文字色，没法画描边，所以「当前项」靠底色加深区分，不靠边框。

⑤ 交互与焦点约定（需要你过目）

触发Ctrl+F（macOS ⌘+F）。会话里：焦点在对话区或底部输入框时生效；文件里：焦点在该文件标签内时生效。其他区域（浏览器标签、终端、设置页、弹窗）不拦截。
⚠ 冲突侧栏的会话搜索框现在已经绑了 Ctrl+F（聚焦它）。方案：焦点在对话区 / 文件标签时，Ctrl+F 归查找栏；焦点在侧栏或其他地方时，保留原来「聚焦会话搜索」。
打开 / 关闭打开：焦点进输入框，已有选中文字就预填它；已打开时再按 Ctrl+F 是全选输入框文字。关闭：Esc 或点 ×，清掉高亮，焦点回到打开前的位置（原位置没了就回到输入区）。
跳转Enter 下一个，Shift+Enter 上一个，到末尾再按回到第一个（计数照常显示 1 / m，不弹额外提示）。输入变化实时重算，并回到第一个命中。当前项不在视口内时自动滚到视口中部。
范围（默认取舍）会话：当前会话已加载的全部消息，包含代码块，不跨会话。折叠着的工具输出和思考内容默认不查（它们没有渲染出来，命中了也看不见）。已渲染但在视口外的消息查得到并能跳过去；还没渲染的长会话消息按文字内容计数，跳过去后精确高亮。文件：当前打开的文件内容。

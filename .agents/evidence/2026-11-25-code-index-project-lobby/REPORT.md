## 同步时间以索引落盘为准

同一轮状态检查结束后，18 项目的测试目录仍分别显示「同步于 2天前 · 3 个文件待更新」「同步于 8天前」或「无同步时间记录」。其中第一个项目的文件行是 12 天前，但最近完整构建在 2 天前；没有可核实的完成时间时，即便检查、任务或文件行很新，也不把它们当作完成时间。

真实 CodeGraph SDK 集成在临时目录里建库并读取桌面状态：无变更同步保留原时间，文件内容未变的完整重建更新完成时间，只删除文件的增量同步也更新时间。另用两个独立 SQLite 库验证项目互不影响、部分构建的文件行不会覆盖已完成的构建。

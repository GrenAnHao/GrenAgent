# 用量统计：按同一筛选核对 Token 与费用

[浅色](light.png) · [暗色](dark.png) · [费用排名](cost.png) · [每日悬浮明细](trend-tooltip.png) · [窄窗](narrow.png)

截图使用真实桌面组件和合成账本报表，不是用户的消费数据。常规视图保留最近会话及逐次调用数据；用量筛选不修改已记录的 Token、金额或来源。

| 核对项 | 验收依据 |
|---|---|
| 项目与标题 | 识别真实工作目录，合并未绑定目录的独立对话。Windows 路径大小写、分隔符和托管 works 目录的 junction 不会造成重复项目；同名但路径不同的项目仍分开。旧 JSON 会话名和侧栏较新的会话名都只展示标题。 |
| 模型与长尾 | 标准请求模型跨供应商分组。切换指标后按该指标重新排名，保留前六名；其余合并为「其他」。用最大余数法显示整数占比，非空合计 100%。逐次调用仍区分原始供应商、请求与响应模型。 |
| 完整账本与费用 | 时间与项目交叉筛选在取最近 500 条明细之前执行，覆盖 UTC 7/30 日边界、范围内零用量日，以及没有助手消息的独立预热。三张图的美元总额与「已记录费用」一致，来源仍拆为供应商报告、目录估算、未知，不将估算当作账单。 |
| 精度与交互 | 总量 26,992,500,000 展示为 27.00B，悬浮仍可查原值；千分位保留在会话及消息计数。项目与模型的费用排名可以不同于 Token 排名，换筛选后保留各图已选指标。 |

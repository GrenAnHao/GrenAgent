# 代码索引工作台验收 · 2026-11-25

## 用户能看到什么

- 未选项目时显示最近六个项目。卡片有完整路径、文件 / 节点 / 边数、状态与同步时间；没有项目时可以直接选择本地目录。下拉支持名称或路径过滤。
- 打开模块会检查全部已知项目，最多同时读三个。卡片、下拉和顶栏读同一份项目状态。检查不会为未索引的项目建索引，也不会为未打开的项目启动文件监听。
- 手动和自动同步共用顶栏位置。扫描时可以先显示已发现数量；解析时显示当前文件数 / 总数；没有实测计数时只报阶段。增量同步仍可读，完成后更新时间、统计和概览。
- 留空默认按目录逐层浏览；平铺可按文件名或引用度排序。更多菜单可以显示隐藏路径和生成产物，不修改项目的忽略规则。`/` 聚焦搜索，方向键选结果，文件夹可用 Enter 展开。
- 右栏按当前可见文件计算语言占比和核心文件前十。引用度是**多少个不同的其他索引文件引用它**，不累计同一文件的重复引用。点击查看源码与文件关系，符号结果仍可查调用者和被调用者。复制得到相对路径，加入对话只插入文件标签，不发送消息。

原先下拉只检查索引文件是否存在，顶栏却读实时状态；已处于空闲的页面在创建手动任务后也可能不再轮询。现在[工作台组件](../../../electron-agent/src/features/agentData/CodeRetrievalPanel.tsx)将三个入口接到[同一个项目状态表](../../../electron-agent/src/features/agentData/useIndexDirectory.ts)。[查询层](../../../electron-agent/electron/app/codeGraph/codeGraphQuery.ts)在分页之前完成过滤、目录分组和整库统计。

# Agent Note: Pi SDK 1.5.1 与 CodeGraph 版本核对

Status: implemented

## Problem

用户要求升级 Pi SDK，并核对 CodeGraph SDK 是否需要同步升级。2026-11-10 查询 npm：Pi 三个直接依赖的 latest 均为 1.5.1；CodeGraph latest 为 1.6.2，与应用当前固定版本一致。

历史决定审计：[1.4.0 升级](../../implemented/architecture/2026-11-01-pi-sdk-1.4.0-upgrade.md) 的三入口精确锁定、shell 查找与五行 diff 补丁仍然适用；本次只替换 SDK 版本，不取代这些决定。[内嵌 CodeGraph](../../implemented/architecture/2026-09-07-embedded-codegraph-sdk.md) 的固定版本和平台打包边界保持不变。

## Decision

- CLI、extensions、Electron 直接 Pi 依赖统一精确锁定 1.5.1，维护三份 pnpm 锁和三份 npm 锁。只更新 Pi 及其必要的传递依赖，不升级其他顶层依赖。
- 保留 TypeBox 工具声明。官方 1.5 引入 pi-schema 作为传递依赖，不为升级而批量迁移工具 schema。提示词增强的 Type 从 typebox 直接导入；Fable topic 使用 Type.String 的 enum 元数据，保持原 JSON Schema 并恢复 string 静态推断。
- 三入口 pnpm-workspace.yaml 只为刚发布的八个 Pi 1.5.1 包增加精确发布时间例外；保留此前例外和构建白名单，不放开命名空间或全局策略。
- CodeGraph 保持 1.6.2，不重建真实项目索引。
- 在当前已有大量未提交改动的工作区做精准修改；升级前的清单、锁和状态快照保存于系统临时目录 `pi-sdk-upgrade-20261110`，不重置、提交或发布用户改动。

## 验证

三入口八包运行图及 pnpm/npm 锁一致性通过；三入口 pnpm 冻结锁联网安装、供应链校验通过。SDK/会话定向组 42 文件 288 例、schema/Fable/元数据组 18 例、Ultra/MCP 等工具组 56 例、CLI 补丁与运行时 19 例、Electron 定向组 160 例、真实 SDK 偏好/Fast 16 例、提示词增强 39 例通过，各组有重叠。提示词增强导入错误先复现失败后修复。

CLI 和 Electron 的 `npm run build` 均通过。noEmit 对照：CLI 82 → 82 条既有诊断，Electron Node 169 → 169，完整输出逐行相同；全仓类型检查仍失败。独立只读审查未发现 P1/P2。

完整命令、原始日志、失败边界与恢复位置见 [验收证据](../../../evidence/2026-11-10-pi-sdk-1.5.1-upgrade/README.md)。测试只使用隔离临时数据、回环 provider 或注入替身，不调用真实付费供应商、不操作用户凭据、不重启正式应用。未改 UI，不跑 UI-harness。

## Alternatives considered

- 只升级 Electron：改动最少，但 CLI 与 extensions 拥有独立 SDK 副本，容易形成类型和运行行为漂移，因此沿用三入口同步。
- 迁移全部工具到 pi-schema：直接使用官方新构建器，长期类型更统一；但当前 TypeBox 常用 JSON Schema 仍受支持，全面迁移会扩大升级范围，只在实际兼容失败处修复。
- 同步升级 CodeGraph：可以获得新版本修复，但当前已是官方最新正式版，无新版本可升，保持现状。

## Consequences

- 三入口继续使用统一正式 SDK，TypeBox 保持原有用法；新增 pi-schema 是上游必需传递依赖，之后升级仍需显式核对八包和两种锁。
- SDK 私有 hook、工具校验和打包资源仍有维护成本。1.5.1 的 Anthropic threads、无工具请求字段和默认 idle cache warming 沿用官方行为；现有显式设置不改，真实 OAuth、远程供应商和最终安装包仍需对应环境验收。
- 冻结锁离线安装因镜像缺少既有 AWS 包发布时间元数据而失败；联网校验通过，离线重现需预热镜像元数据，不为此关闭供应链校验。
- 起始工作区已有旧 tsc 生成的未跟踪 JS。只将会遮住本次 TS 修改的三个生成 JS 移入临时快照目录备份，确保检查与生产构建消费实际源码；未清理其他生成文件或用户改动。

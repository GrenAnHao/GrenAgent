# Agent Note: Pi SDK 1.4.0 与三入口补丁一致性

Status: implemented

## Problem

CLI、扩展和 Electron 当前运行依赖图中的七个 Pi 包均为 1.3.0。用户要求升级到已发布的 1.4.0；本仓库依赖会话私有钩子、共享模型运行时、压缩和请求头契约，不能只更新声明。CLI 与扩展的 shell 查找和 edit 预览补丁也未覆盖 Electron 的安装副本。

已有决定部分重叠：保留 [1.3.0 升级](../../implemented/architecture/2026-10-17-pi-1.3.0-upgrade.md) 中的 custom/user 事件分流；保留 [Windows bash](../../implemented/architecture/2026-10-14-windows-bash-git-bash-like-pi.md) 委托 SDK、显式 shellPath 和 Git Bash 的行为。本次只调整后者的查找增强适用范围，不改 bash 与 PowerShell 的工具分工。

## Decision

- 三入口直接 Pi 依赖精确锁定 1.4.0，更新实际使用的 pnpm 锁及仍被 CI 使用的 npm 锁；保留旧 bun 锁，不引入 Chord、main API 或 pi-schema。
- 先保存当前 dirty 文件和 1.3.0 行为、类型检查基线，再安装官方包。比较实际解析依赖图，而非残留 node_modules 目录。
- 将已有窄范围 shell 查找增强和显示 diff 五行偏好一致应用于三入口；以官方 1.4.0 文件为底，保留 Windows Store alias、WSL 等上游修复。新增 unified patch 格式仍用官方默认值。
- 补丁可重复执行；未知上游形状报错且不写入。安装脚本显式指定目标项目，避免只修改脚本所在 CLI 的副本。
- 使用隔离目录、回环 provider 和真实 SDK 验证工具刷新、工作目录切换、请求头、压缩及恢复；知识服务和 Repo Wiki 继续走现有共享调度与独立子进程。

## Alternatives considered

- 保持 1.3.0：无需承担私有接口风险，但不符合本次明确升级要求。
- 使用范围版本或跟进 main：能自动获得后续修复，但会放大三副本漂移和未发布接口风险；本次只锁正式 1.4.0。
- 删除现有本地补丁、完全使用官方文件：维护成本最低，但会悄悄改变现有 CLI/扩展行为；本次保留窄范围目标并增加一致性测试。
- 保留各入口补丁差异：改动更少，但同一项目在 CLI 与 Electron 使用不同 shell 查找和预览上下文；选择显式统一，局部取代旧笔记对额外查找分支的拒绝。

## Consequences

- 三入口实际运行图中的七个 Pi 包及 pnpm/npm 锁全部为 1.4.0。依赖精确锁定，之后升级需显式修改。
- 私有钩子暂时仍依赖 SDK 内部字段，但有真实会话回归证据；本次无业务兼容代码需要更改。
- 1.4 摘要输出预算采用模型输出上限，不再受 `generateSummary` 兼容参数 `reserveTokens` 限制；上下文压缩余量配置仍保留，测试按真实 HTTP 请求验证。
- 新补丁按官方源码结构校验，未来结构变化时安装失败关闭；三副本 postinstall 需能访问仓库的 CLI 补丁脚本。

## 验证

通过：SDK/会话 238 项、配置/auth 离线 62 项、工具提示词门禁 4 项；知识与 Repo Wiki 当前原组 34 文件 183 项；补丁 11 项；资源定向 29 项。CLI 和 Electron 最终生产构建通过，Repo Wiki 专用类型检查通过。真实隔离 Agent Host 启动/MCP/关闭、最终 Repo Wiki IPC 关闭及 codemode 字节码加真实 WASM 执行通过。

全量类型检查保留 Electron Node 129、CLI 82、知识 strict 4 条既有诊断，和最终 1.3 基线对照无新增。用户并发的知识预算/测试改动完整保留。没有付费请求、正式应用重启、凭据/文档修改、提交或发布。

边界：最终 installer/asar、真实 OAuth/供应商/Vertex ADC/图片转换未验证；生产字节码存在与 1.3 同源的 ADC 动态导入警告，裸构建默认 WASM 顶层定位未作为通过项。没有把显式传入 WASM 的 worker 兼容测试称为最终安装包端到端通过。

证据目录：`.agents/evidence/2026-11-01-pi-sdk-1.4.0-upgrade/`。详细结果、命令、原始日志和失败调查见 [验收证据](../../../evidence/2026-11-01-pi-sdk-1.4.0-upgrade/README.md)。

## Risks

私有 SDK 成员没有稳定性保证；补丁依赖上游文件结构，必须失败关闭。当前工作区有大量既有未提交改动，保留原样并使用任务前快照确认本次范围。测试 provider 仅回环，不代表真实供应商联网或 OAuth 交互已验证。

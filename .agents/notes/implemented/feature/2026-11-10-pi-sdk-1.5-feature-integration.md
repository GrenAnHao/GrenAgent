# Agent Note: Pi 1.5 新能力接入现有设置与生产运行时

Status: implemented

## Problem

Pi SDK 1.5.1 升级已完成，但新版兼容字段、缓存预热控制和官方 OAuth/Bedrock 懒加载入口还未完成产品接入。用户要求开始接入这三项；范围不包含照搬终端专属 UI、修改真实凭据或发起真实模型请求。

历史审计：[SDK 升级](../../implemented/architecture/2026-11-10-pi-sdk-1.5.1-upgrade.md) 负责版本与兼容基线，本篇部分重叠但不取代；[OAuth 凭据所有权](../../implemented/architecture/2026-11-08-pi-native-provider-oauth-ownership.md) 和 [Anthropic 档位](../../implemented/feature/2026-10-14-anthropic-thinking-ladder-aligned.md) 继续适用，不更改认证流程或已存思考映射。

## Decision

用户后续撤回通用设置的缓存预热三档控件；当前不再挂载或通过一般表单读写该项，SDK 已存模式不被清空。见[界面收敛](../simplification/2026-11-10-remove-chat-inspection-panels.md)。下文预热控件验收为此前候选的历史证据；SDK 协议、认证与懒加载兼容继续有效。

- 在现有模型兼容目录与卡片中增加 SDK 1.5 对应字段，按实际 API 过滤，保存与重载保留 false/缺省的区别，默认交给 SDK，不给所有模型硬塞兼容开关。
- 在现有通用设置加入关闭、仅运行中、运行中与空闲三项缓存预热选择。直接回显并保存 Pi 的 canonical settings.json，不额外保存 env 模式；未修改该项时不写 SDK 设置。活会话复用官方 setCacheWarmingMode 调度/取消，热更新复用已有配置通知，不另建计时器。说明预热可能发起计费请求，测试不执行真实付费预热。
- 在真正使用的 Node 运行时实例中注册官方 lazy-oauth / lazy-bedrock-provider，覆盖桌面主进程、agent host/worker 和 CLI；以生产分割/字节码产物的隔离加载烟测验收，不只检查源码 import。
- 生产 CJS 输出启用 Rolldown strictExecutionOrder，避免 virtual-modules 在 IMAGE_MODELS 导出初始化前执行。此选项修复正式 agent-host 和 pi-worker 入口实际暴露的循环，不手动把所有 SDK 模块合成一个大块，也不修改 bytecode-loader。
- 保持当前已升级的依赖与其他用户改动，不提交、不发布、不重启正式应用。旧生成 JS 只在遮挡本次改动时备份对应文件，不做全仓清理。

## Alternatives considered

- 只升级底层、继续手写 models.json/settings.json：修改最少，SDK 已支持大部分行为；不采用，因为用户已要求把这些能力接入现有产品入口，设置页保存还会过滤不认识的字段。
- 迁移全部设置与模型编辑器到 SDK 自动生成 UI：长期字段覆盖更全；不采用，本次只是给现有成熟链路补缺，整体迁移会改变交互和现有存储契约。
- 全量静态导入 OAuth/Bedrock：能绕开动态定位问题；不采用，SDK 已提供官方字面量动态 import 的懒加载入口，应保留按需加载和现有认证所有权。
- 为缓存预热增加「跟随 Pi」env 覆盖并劫持 SettingsManager getter/setter：能避免改 SDK settings.json；不采用，SDK 的 cacheWarming 不读取 applyOverrides，维持影子设置需要改写实例方法和抑制持久化。直接让用户操作官方 canonical 偏好更简单，也不会有两处值互相覆盖。

## Consequences

- 新能力沿用原设置和模型卡，SDK 继续拥有协议、认证与预热调度；升级时仍需核对字段/API 和实际 Node 实例的注册，不能只改根包版本或只看构建 exit 0。
- 缓存模式以 SDK 全局偏好为唯一来源，用户显式修改会影响共享该 agentDir 的会话；其余应用设置保存不会重写缓存偏好。预热可能产生费用，界面说明此行为，不默认替换已有 SDK 偏好。
- CJS 严格初始化会改变分块执行安排，维护时保留真实字节码入口烟测。其他动态导入路径、正式 OAuth 登录/刷新、远程厂商和最终安装包不在本轮离线证据内。
- 当前工作区有旧 tsc 输出，遮挡本次 TS 的对应生成 JS 已备份到系统临时目录，其他用户改动不清理。生产产物写 out-pkg，不覆盖 dev/localrun；没有制作安装包、重启正式应用、提交或发布。

# Agent Note: 技能、命令、规则页去重并防止丢草稿

Status: implemented

## Problem

MCP 页整理后，用户要求把技能、命令、规则三页的同类问题一起改掉。

- 命令和规则：改到一半点别的条目或「新建」，草稿被直接替换，没有提示。没改动也能点保存，看不出哪些改了没存。
- 重复说明：命令的「全局」徽标、「全局可用」、两处参数用法；规则的「开关立即生效」「修改后需要保存」「发送时加入上下文」和列表底部长提示（窄列里在「上 / 下文」中间断行）。
- 空标签和脚注：「全部命令」列表标题、命令和规则贴在列表底部的提示、技能页的「本机技能」标题和长列表末尾的脚注。
- 文字不一致：空白处写「点『新建』」，按钮叫「新建命令 / 新建规则」；antd 给两个汉字的按钮插空格，显示成「删 除」。
- 规则：详情右上的开关没写状态；适用模式一个都不选表示全部，可五个按钮看起来都没选；停用的规则在列表里不变淡。
- 技能：整页滚动，往下翻页头和工具都滚走；行内只有名字和简介，看不到来源和路径；每行都写「已启用」；删除紧挨开关；刷新和打开目录只有图标；首字母头像大多相同；技能多时没有筛选。

## Decision

- 命令和规则加「未保存」判断。命令比较名称、描述、正文；规则比较标题、正文、范围、模式。规则的开关当场写盘，不算未保存。新建的草稿填了内容就算改过。
- 有未保存的修改时，换条目或新建先用 `useAskConfirm` 确认，取消就留在原草稿。没改过就同步直接换，不等确认框，宽窄切换、返回列表再打开同一条的行为不变。
- 标题旁显示「未保存」；保存按钮只在改过且合法时可点。
- 去掉重复说明：命令只在提示词模板标题右边写一次参数用法；规则的基本信息写「开关立即生效，其他修改需保存」，正文标题只写 Markdown。列表底部提示移到页头说明，规则的保存目录改写在范围控件下面（`保存到 ~/.pi/agent/rules` / `.pi/rules`）。
- 空白处文字对上按钮名；删除按钮和确认按钮关掉 `autoInsertSpace`。
- 规则详情开关旁写「已启用 / 已停用」；模式前加「全部」，没选模式时亮起，点它清空；停用的行变淡到 0.55。
- 技能页：页头和工具行不动，只有目录滚动（`inner` 和目录用 `flex: 1 1 0px`，目录保底 120px，再矮才整页滚动）。行内加来源和路径，去掉头像和「已启用」，删除前加分隔线；刷新、打开目录带文字；超过 8 个技能出筛选框，按名字和简介筛；「本机技能」标题去掉，那一行只放筛选和视图切换；脚注并入页头说明。

## Alternatives considered

- 草稿按条目缓存，切换不丢也不用确认：体验最顺。但要给每条命令和规则维护一份草稿，还要处理改名、删除、工作区切换后的旧草稿，复杂度和出错面都更大。先用确认框挡住丢失。
- 只在离开时确认、不禁用保存：改动最少。但看不出哪里改了，未改动时点保存会触发一次无意义的写盘和重载，所以加上未保存标记并禁用。
- 去掉规则列表里的开关，只留详情一个：重复最少。但列表开关是批量启停的快捷入口，现有测试和使用习惯都依赖它，所以保留两个，给详情这个写上状态。
- 技能加详情页显示正文：信息最全。但要新增读取 SKILL.md 的接口，超出本次范围，先显示来源和路径。

## Consequences

命令和规则在同一页里换条目不会再悄悄丢草稿。仍未覆盖：切到别的扩展页签会卸载面板，草稿照样丢，需要另外处理。未改动的条目不能点保存。技能页高度不够时仍会退回整页滚动。没有改动文件格式、设置字段或主进程接口。

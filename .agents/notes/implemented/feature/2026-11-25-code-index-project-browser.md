# Agent Note: 代码索引按项目展示实时状态，按目录浏览已提交的索引

Status: implemented

## Problem

下拉框的目录探针和页头读的不是同一份状态。手动任务创建后若此前是 idle，不会启动轮询；统计总数也不是这次任务的实际进度。分页文件的第一页不足以推断全项目的目录、语言分布或依赖排名。

## Decision

最近项目、选择器与顶栏读取同一个按项目路径分组的状态表。打开模块即检查全部已知目录，最多并发三个请求；空闲时 45 秒复查，有同步任务时每秒更新。读状态不启动监听、不建索引。桌面 IPC 走本进程管理接口，在状态中附该项目最近一次手动任务的持久化回执；普通 RPC 不附任务记录。Windows 路径斜杠和盘符大小写不同仍指向同一任务。

进行中的任务只报告 SDK 给出的阶段和计数：扫描阶段总数未知时仍可显示已发现的文件数，解析阶段有分母才显示完成数/总数。阶段变化时清掉旧分母。增量同步不打断阅读；完成回执触发统计与查询重读。卡片和顶栏用 syncedAt 表示最近一次落盘的构建。从项目索引库读取桌面构建回执和 SDK 的完整构建记录；已完成的旧索引也可使用文件行的 indexed_at。SDK 的 lastIndexedAt 继续仅表示最新文件行时间。lastCheckedAt 只记状态读取，调度和任务时间均不作为同步时间。卡片和顶栏不会因一次读失败把未知数据当成零，切换工作区或显示规则后不接收前一次的查询响应。

大厅按最近访问顺序列出所有项目，筛选和批量同步使用同一个状态表。卡片的「立即同步」沿用增量策略；「立即重新索引」明确要求完整构建，进入同一个写队列。从列表移除只隐藏本模块的项目，保留会话、源文件和索引，重新添加即可恢复。

浏览查询在读线程内过滤隐藏路径及生成产物，按完整文件集分组、排序再分页。引用度是文件依赖图的入度（不同外部引用文件数）；前十和语言占比使用同一可见文件集。切换显示规则不修改索引。文件引用复用现有聊天输入框的文件标签，不发送消息。

## Alternatives considered

- 用调度或任务的成功时间可以显示最近的活动，但无法区别检查与写入。只读文件行也不够：全量重建可复用全部文件，增量删除没有新文件行可供计时。因此全量构建成功或增量确有变更后，在同一份索引库中记录完成时间；无变更的增量不写。没有可信记录时显示未知。
- 复用轻量的索引文件存在性探针能更快填满卡片，但不能判断过期、任务阶段或统计。保留旧接口给原调用方，工作台只读完整状态。
- 全部文件送到渲染层实现最直接，却会恢复大项目的全量 IPC 和首屏开销；逐目录、逐页取数。
- 调度器的 idle 不需要任务存储，但两次轮询之间结束的短任务也会返回 idle，不能据此宣告完成。

## Consequences

卡片统计的是项目整个索引；语言占比与排名的候选是当前显示规则可见的文件。入度数的是整个索引中引用这个文件的不同外部文件，不是同一个调用出现的次数。默认隐藏点路径、常见构建目录和 SDK 标记的生成文件，切换开关不改索引或用户的忽略文件。原有调用方不传新参数，保留原来的返回范围与分页契约。

首次建立或全量重建时没有可读的新索引；工作台原位显示阶段，完成后才开始浏览。模块关闭时停止轮询，重新打开按持久化任务状态恢复，不在渲染层虚构完成或把后台任务取消。

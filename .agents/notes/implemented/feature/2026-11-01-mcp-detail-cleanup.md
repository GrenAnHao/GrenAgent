# Agent Note: MCP 详情去重、状态文字统一、操作分组

Status: implemented

## Problem

用户指出 MCP 工作台有多处设计不满意。详情头和「连接配置」重复写连接方式、来源和工具暴露；目录与详情的状态文字由两套规则拼出，同一台服务器写法不同；操作行有一个无意义的「服务器连接」标签，删除紧挨编辑；「默认策略」只是文字；工具多时没有筛选，也不能整组设权限；停用后的权限看不出不生效；空态和页面说明让人点一个只有图标的「重载」；目录计数、相同图标和贴底脚注都是重复信息；登录行直接露出完整登录网址，「复制」要等打开失败才出现；连接配置写「只读摘要」，编辑却在顶部。

## Decision

- `mcpPresentation.ts` 只留一份 `mcpStatusText` / `mcpStatusColor`，入参包含 `enabled`，目录与详情都用它：未启用、需要登录、连接中、连接失败、`已连接 · N 工具`、探测中、`缓存 · N 工具`、未探测。
- 详情头保留连接方式、暴露、认证和来源（写全称「项目配置」等）；「连接配置」只写启动命令/服务地址和工作目录，标题右边放「编辑」（沿用 `mcp-edit-<name>`）。
- 详情操作行：开关加「已启用 / 已停用」文字、带文字的「重载」，删除改成红色文字按钮推到最右。紧凑卡片（只在测试里用）保持原图标操作。
- 工具权限标题写数量；多于 1 个工具且父组件提供 `onPermChangeMany` 时给「全部设为 自动 / 需审批 / 禁用」。整组写入在 `ExtensionsPanel` 里用一次 reduce 完成。多于 8 个工具时出筛选框，按短名过滤。
- 停用的服务器：工具列表降到 0.55 透明度并写「服务器已停用，权限在启用后生效。」，控件仍可改。
- 空态提示改成「点上方「重载」…」，未启用时写「启用后可加载工具。」；页面说明去掉重载那句，改写「开关与权限即时生效」，目录底部脚注删除。
- 目录去掉「服务器 N」行和统一的服务器图标，状态点放大到 8px 移到最左。
- 连接配置写全：启动命令带参数（含空格的参数加引号）、工作目录、环境变量名；远程写服务地址和请求头名。环境变量和请求头的值可能是密钥，只列名字并写「值已隐藏」。
- 详情栏改成列布局：连接配置贴在底部不动，只有工具列表滚动。卡片、工具区和工具列表都用 `flex: 1 1 0px`，否则 Chrome 按内容高度算最小尺寸，列表不会收缩；工具列表保底 120px，窗口矮到放不下时才退回整栏滚动。连接配置最多占详情 45%，超出自己滚动。
- 登录行只显示「需要在浏览器中登录 · 域名」，完整网址放 `title`；「登录」和「复制链接」常驻；打开浏览器失败时改写成「无法打开浏览器，请复制链接登录」。详情里登录行用警示色框。

## Alternatives considered

- 逐个调用 `onPermChange` 实现「全部设为」：改动最少，接口不变。但每次都基于同一份旧 `policyRaw`，React 批处理后只剩最后一个工具生效，所以新增一次性写入的 `onPermChangeMany`。
- 把每行三段 Segmented 换成下拉框：行更紧凑。但当前状态要点开才看得到，且会打破现有 probe 和使用习惯；改为小号 Segmented 加筛选与整组设置。
- 工具说明：用户提到缺说明，但运行状态和缓存只有工具名，没有描述字段；补描述要改主进程协议，不在本次范围。
- 编辑按钮在操作行和连接配置各放一个：入口更多。但同一动作出现两次正是本次要去掉的重复，只保留连接配置里那个。

## Consequences

同一台服务器在目录与详情显示完全相同的状态文字。紧凑卡片的缓存状态从「N 工具」变成「缓存 · N 工具」。整组设权限只写一次策略文件。登录网址仍可通过悬停和复制拿到，不再占满一行。没有改动 MCP 配置、策略文件格式或主进程接口。

常见问题 / 06

关于 GrenAgent。

先把运行边界讲清楚，再谈 Agent 能做什么。

GrenAgent 是完全离线的吗？＋

不是。GrenAgent 的桌面运行时、会话和索引以本地为主，但调用云端模型供应商时仍需要网络。是否使用本地模型取决于你的供应商配置。

它当前使用什么技术栈？＋

当前主线是 Electron 桌面应用，界面采用 React 19 与 Vite；Agent 运行时基于 Pi SDK，并由独立子进程承载。早期 Tauri 版本已经封存，不代表当前主线。

可以连接自己的模型和工具吗？＋

可以配置多个模型供应商，并通过 MCP 与 Skills 扩展工具和工作流。具体兼容范围以仓库当前实现为准。

Agent 会不会擅自修改文件？＋

工具执行受会话审批策略、路径保护、危险命令拦截与沙箱约束。你可以按任务选择只读、请求批准、自动审批、工作区编辑或完全权限。

项目采用什么许可证？＋

当前仓库采用 PolyForm Noncommercial License 1.0.0。商业用途需要另行获得书面授权，具体以仓库中的 LICENSE 与 COMMERCIAL.md 为准。
